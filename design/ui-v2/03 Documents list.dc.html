Archetype 03

Documents list

The list-page archetype: stat strip, filter row, then a 36px-row table that is the only scrolling region. Columns are the ones the app already has. Paperless ids and filenames are mono, the duplicate count carries an inline meter whose track derives from ink so it survives hover and selection, OCR is the row's one shape-plus-word status, and selection shows an accent inset edge with the bulk bar pinned to the bottom edge.

Empty result

The filter row and table header stay put so the user can see what caused the empty result. One sentence says what happened and what to do next, with a single outline button. No illustration.

Narrow

The table becomes a row list rather than a horizontal scroll. Each row keeps its identifier, title, classification and the same status vocabulary; the meter drops out because the count alone carries it at this width. Checkboxes go to 16px in a 44px target, and the bulk bar stacks its actions.
