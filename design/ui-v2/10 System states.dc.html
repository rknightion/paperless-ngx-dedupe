Archetype 10

System states

First load, in-flight actions, nothing to show, something broke, and the two toasts. All written, none decorated: no illustrations, no emoji, no full-page spinners over content that already exists.

Skeletons match the real row height and column widths and only appear after 200ms. A refresh keeps the data on screen and moves the freshness label to a mono refreshing label. Errors appear in the region that failed with the retry attached. Toasts confirm work that finished away from the current view, and never carry an error the user has to act on.
