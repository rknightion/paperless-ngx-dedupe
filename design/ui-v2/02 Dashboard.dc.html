Archetype 02

Dashboard

Dedupe posture first, then the work that needs a person. The stat strip is divided cells rather than card tiles, statuses read as shape plus word, and the two charts sit on the petrol-derived series palette. The first-run checklist now has a completion rule: once all three steps pass it collapses to the single dismissible line at the top, and it only returns if readiness regresses.

The narrow dashboard is in archetype 01, where it carries the shell variant.
